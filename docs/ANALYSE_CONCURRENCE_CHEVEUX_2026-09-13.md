# KURLA — Analyse concurrentielle : plateformes et modèles d'analyse cheveux (13/09/2026)

Consigne : regarder ce que font les concurrents, analyser leurs plateformes
et leurs modèles d'analyse, et en adopter ce qui sert KURLA.

**Limite de méthode (fixée d'emblée)** : KURLA adopte les **modèles**
(architecture du quiz, dimensions d'analyse, boucles de personnalisation,
ton de communication scientifique). KURLA ne copie **jamais le contenu**
(textes, images, marques, formulations de marque) — ce serait une
contrefaçon, et ça n'apporterait rien : notre avantage, c'est le contenu
sourcé original en français pour les cheveux 3B–4C et les peaux
mélaninées.

---

## 1. Les acteurs analysés

### 1.1 Function of Beauty (US, DTC)
**Modèle** : quiz en ~25 questions (historique des cheveux, préoccupations,
objectifs, préférences olfactives) → algorithme → **formule personnalisée**
(bouteille individuelle, ~12 milliards de combinaisons annoncées) →
abonnement. Machine visible en pop-up (la formule est fabriquée devant
vous). Le quiz est aussi le moteur de contenu : les créateurs filment leur
vrai quiz, la formule « révélée » devient le second acte vidéo
(quiz-to-creator).
**Ce que KURLA adopte** : (a) le quiz multi-étapes avec **historique** —
KURLA a déjà le journal + la boucle d'observations, c'est l'équivalent ;
(b) la **révélation immédiate et visible** du résultat (KURLA le fait :
le résultat porte la routine complète, pas un e-mail) ; (c) la preuve par
la différence — « deux profils, deux routines » est déjà verrouillé par
nos bancs (routine grasse ≠ routine sèche ; LCO ≠ locks).
**Ce que KURLA ne copie pas** : la formulation sur mesure (industrial,
hors périmètre KURLA) ; l'opacité de l'algorithme (KURLA est **hybride
transparent** : conseil déterministe sourcé + résumé IA signalé — c'est
notre avantage de confiance).

### 1.2 PATTERN Beauty (US)
**Modèle** : Curl Guide public (3B, 3C, 4A, 4B, 4C) + **porosité +
densité** → chaque type est raccordé à une **routine complète** (pas un
produit). C'est le point le plus proche de l'ambition KURLA côté anglo.
**Ce que KURLA adopte** : le triptyque **motif + porosité + densité** comme
dimensions minimales d'un profil (KURLA a motif + porosité + cuir chevelu
+ priorité + rythme — la densité et l'élasticité restent des questions en
attente d'arbitrage, cf. §4).
**Différence KURLA** : PATTERN guide vers leurs produits ; KURLA guide
vers la méthode d'abord, le produit ensuite — et le tout est sourcé.

### 1.3 Carols Daughter (US)
**Modèle** : Curl Quiz en **5 étapes** (type de cheveux, préoccupations,
produits adaptés) ; le site liste explicitement les 4 dimensions d'un
« profil complet » : porosité, densité, élasticité, cuir chevelu.
**Ce que KURLA adopte** : la confirmation que le marché a convergé sur les
dimensions du profil (KURLA coche déjà 5/6 : motif, porosité, cuir
chevelu, priorité, rythme — manque densité/élasticité).

### 1.4 Kinky Curly (US)
**Modèle** : charte de typage 1A–4C + **test du verre d'eau** (porosité)
+ guides produits. Le test du verre d'eau est devenu LA référence
populaire — et la communauté experte le conteste (voir RECHERCHE §6.3).
**Ce que KURLA adopte** : rien à copier tel quel — le test du verre d'eau
est déjà dans le diagnostic KURLA (étape porosité) avec sa nuance
« guide grossier ». **KURLA va plus loin** : la fouille documente le
**test du spray** plus fiable → le conseil le propose en alternative.
C'est le genre de « ouvrir les yeux » qui fait la différence : on corrige
gentiment une croyance dominante du marché.

### 1.5 Kérastase — Curl Manifesto (FR/international, pro)
**Modèle** : gamme Curl / Very Curly / **Coily** ; communication
scientifique par actif (céramide biomimétique « 4 ans de recherche »,
protection UV / eau du robinet / chaleur) ; récit d'inclusion (« toutes
les textures ont la même structure biologique, mais les boucles n'ont
jamais été célébrées ») ; rituel salon ; claims mesurés.
**Ce que KURLA adopte** : (a) le **ton** — la science comme narration
humaine, pas comme jargon ; (b) la structuration par type de boucle dans
le discours ; (c) l'importance du **rituel pro** (KURLA a déjà le module
professionnel).
**Différence KURLA** : Kérastase communique des claims de marque
(« 94 % de définition ») ; KURLA ne fait **aucun claim de marque** —
chaque affirmation est une source, et les limites sont dites (c'est la
confiance, c'est l'unique).

### 1.6 Curlie (US)
**Modèle** : plus grande communauté curly/coily : annuaire des coiffeurs
curl-friendly, guides par type de boucle, contenu communautaire.
**Ce que KURLA adopte** : la **connaissance communautaire comme matière
première** (co-wash, LCO/LOC, wash & go, shrinkage) — KURLA le fait déjà
vocabulary-wise (le diagnostic parle la langue des textures).
**Différence KURLA** : Curlie documente ; KURLA **recommande** (routine
contextuelle + produits + suivi) — et source ce que Curlie relate.

### 1.7 Marques éducatrices (SheaMoisture, Melanin Haircare, Cantu, Mielle)
**Modèle** : éducation générale par type (curl education), quiz de
marque orientés panier.
**Lecture** : l'éducation existe, mais elle sert le panier ; personne ne
fait d'**éducation sourcée et neutre** en français. C'est l'espace KURLA.

## 2. Ce que personne ne fait (l'espace « unique au monde »)

1. **Un diagnostic cheveux dont chaque étape est justifiée par un
   mécanisme vérifié** (pourquoi/comment/à attendre) — les concurrents
   recommandent, ils n'expliquent pas la physique de la fibre.
2. **Une base de savoirs publique et sourcée** en français, 3B–4C +
   mélanine : les sources (trichoscopie afro, eumélanine, mémoire des
   liaisons hydrogène, normes de densité) existent dans la littérature —
   personne ne les a traduites en conseil grand public en français.
3. **Des « ouvertures d'yeux » contextuelles** : 3 faits choisis pour le
   profil (la tempes concentre les cheveux fins ; le shrinkage n'est pas
   une perte ; le test du verre d'eau est perfectible…) — les quiz
   concurrents répondent ; KURLA fait **découvrir**.
4. **L'honnêteté radicale** : aucun produit ne fait pousser ; le typing
   Walker est visuel ; la CGM a des limites ; un cuir chevelu qui gratte
   sous tresses est un signal de détendre, pas d'endurer. Les concurrents
   vendent ; KURLA dit la vérité — c'est ce qui fait revenir.
5. **La boucle** : observations J+7/14/30 + profil enrichi +
   réévaluation — aucun quiz concurrent ne fait de suivi dans le temps.

## 4. Suites proposées (à arbitrer, non exécutées)

1. **Deux questions de plus au diagnostic cheveux** (densité : fine /
   moyenne / dense ; usage de la chaleur : jamais / parfois / souvent) —
   les concurrents l'ont, la routine gagnerait (protection contre la
   chaleur, quantités) ; touche page + profil serveur + IA → chantier.
2. **Élasticité** au diagnostic (test d'étirement humide) — dimension
   documentée (Carols Daughter), utile au conseil « fibre cassante ».
3. **Seconde fouille thèses FR** (accès payants) — trichoscopie,
   défrisage en France, coiffures protectrices et cuir chevelu.

## 5. Pôle peau — acteurs et lecture (13/09/2026)

### 5.1 Marques dermatologiques (La Roche-Posay, CeraVe, Eucerin, Avène)
Éducation par actif + gammes par besoin + ancrage « validé par les
dermatologues ». Force : la confiance institutionnelle. Faiblesse :
conçu peaux claires d'abord (les références phototype IV–VI arrivent
tard et restent mineures) ; l'éducation ne s'adresse pas aux problèmes
spécifiques peaux foncées (HPI, lumière visible, friction).
**KURLA adopte** : le sérieux de l'explication par actif (sans claims de
marque), **sans copier** leurs contenus. **Différence** : le point de
départ KURLA, c'est le phototype IV–VI déclaré avec consentement — pas
un postérieur.

### 5.2 Quiz → produit (Function of Beauty, Curology, Traya)
Quiz long → formule/plan personnalisé. Curology = prescription
(sortie de périmètre KURLA : on ne prescrit pas, on conseille en
cosmétique). Traya = quiz « causes profondes » (santé interne) — modèle
d'interview à couches (symptôme → cause → plan).
**KURLA adopte** : l'interview à couches déjà présente (le diagnostic
demande les faits, le conseil explique les causes, le suivi mesure) ;
**refuse** l'opacité (notre hybride est transparent et sourcé).

### 5.3 Niche « skin of colour » (Babymelon, Melanin Haircare, marques communautaires)
Éducation par l'expérience, forte identité, peu de preuve sourcée ;
quiz de marque orientés panier.
**KURLA adopte** : l'identité et la langue (la peau mélaninée est le
point de vue, pas un segment) ; **va plus loin** : chaque affirmation a
sa source (travaux de Kligman, révisions HPI 2024/2025, comité UE
parfums) — c'est l'écart « unique au monde ».

### 5.4 Références institutionnelles (AAD, BAD, Cleveland Clinic, Skin Cancer Foundation)
Le contenu d'autorité existe — mais en anglais, orienté médical, et
presque jamais traduit en conseil cosmétique francophone pour peaux
foncées. KURLA ne s'y substitue pas (on renvoie vers l'avis
professionnel quand la frontière est dépassée) : KURLA **traduit en
gestes** ce que ces institutions documentent — SPF 30+ quotidien,
ne pas toucher les lésions inflammatoires, écran coloré pour les
pigmentaires, lecture INCI.
