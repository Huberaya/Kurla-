## 2. La recherche web — ce que demandent réellement les porteuses et porteurs

Synthèse des sources consultées (anglophones surtout ; la communauté locks francophone renvoie aux
mêmes FAQ) :

1. **« Depuis combien de temps ? » — la maturité décide de tout** : les guides segmentent tous le
   programme par âge — starter (0–6 mois : lavage 1–2 semaines, pas de lutte contre le
   shrinkage), teenage (6–12 mois), mature (1 an + : entretien plus espacé, lavages plus fréquents)
   [eathealthy365 2026 guide ; dreadlocksextension.com maintenance 2025]. La FAQ n°1 des débutants :
   *« mes locks raccourcissent / semblent désordonnées, est-ce normal ? »* — réponse constante :
   le raccourcissement construit la matrice, le presser contre le shrinkage **ralentit** le processus
   [r/Microlocs, thread length-retention].
2. **« Palm rolling ou interlocking ? À quel rythme ? »** : rythme recommandé 4–6 semaines, jamais plus
   serré ni plus souvent — le retwist trop fréquent et trop serré amincit et casse [annieinc.com
   retwist guide ; The Kinky Apothecary]. Et le geste que les modérateurs répètent : le palm rolling
   **quotidien** est une erreur — le frisottis entre deux séances est normal [r/Dreadlocks « Palm
   Rolling vs Retwisting »]. Le freeform est une méthode à part entière : « ça ne se retord pas, ça se
   sépare » [eathealthy365 FAQ].
3. **« Mes locks sentent / me grattent — pourquoi ? »** : cause n°1 listée partout : **dormir avec des
   locks humides** et les produits qui déposent (cire, beurres, silicones), pas le lavage ; remèdes :
   rinçage long (5 min), séchage complet avant la nuit, clarifiant, seulement si l'odeur revient
   [miradreadlocks « Do Dreads Smell? » ; dreadlove.net itchy scalp ; dreadlocksextension].
4. Deux thèmes très posés déjà **couverts** par le moteur (résidus : shampoing sans résidu +
   hydratation légère ; démêlage/peigne : interdit par cycle locks, prouvé D5) — pas de question
   ajoutée, ce serait du remplissage.

## 3. Ce qui a été fait — trois réponses, douze effets rendus

### 3.1 Le questionnaire (jamais posé hors locks ; adulte comme enfant-locks, le gardien répond)

- **« Depuis combien de temps vos locks sont-elles lancées ? »** — neuve (<6 mois) / ado (6–12 mois) /
  mature (1 an + ) / je ne sais pas.
- **« À la racine, vos locks sont entretenues comment ? »** — palm rolling-retwist / interlocking /
  libre pousse (freeform) / je ne sais pas.
- **« Après le rinçage, vos locks sèchent… ? »** — toujours sèches avant la nuit / sèche-cheveux
  tiède / il m'arrive de coucher humide / très longues à sécher avec odeur / ça dépend.

### 3.2 Les effets (chacun vérifié dans le rendu, pas dans les drapeaux)

| Réponse | Effet |
|---|---|
| neuve | l'étape « Racines : le travail de la lock » ajoute : « le raccourcissement fait partie du processus — la lock construit sa matrice avant de s'allonger » |
| ado | « la maturation prime encore sur la perfection du tracé » |
| mature | « elles supportent un entretien plus espacé et des lavages plus fréquents » |
| palm | la consigne plafonnée : « surtout pas tous les jours… le léger frisottis entre deux séances est normal » |
| interlock | le plafond de la méthode : « séance tenue (~8 semaines, jamais moins) ; serré au-delà, la racine perd sa prise » |
| **freeform** | **remplace** la consigne retwist (hebdo **et** entre-deux lavages) par la vraie méthode : séparation racine par racine, nuque et contour, lavage sans résidu — « une méthode, pas un abandon » |
| humide | nouvelle étape du jour de lavage « **Sécher les locks jusqu'au cœur** » : « coucher des locks encore humides est la première cause d'odeur… ne se coucher que des locks sèches au toucher profond » |
| lentes | la même étape, version rinçage long + produits allégés + « clarifiant seulement si l'odeur revient — jamais du parfum sur de l'humide » |
| sec / seche | confirme le bon réflexe, ajoute la vérification au toucher (« racine tiède = racine humide ») |
| inconnu (×3) | **rien** — routine JSON strictement identique à avant (prouvé) |

Plus une ligne de résumé par réponse connue (mêmes gates que la routine — pas de liste recopiée).

### 3.3 Les gardes (leçon D9/D10, appliquée avant qu'il faille l'apprendre)

- Les trois réponses n'existent que `lockedNow` (texture locksee OU style locks), whitelistée dans
  `flags()` ; rémanence d'un ancien profil locks devenu bouclé/perruque → ignorée à la source.
- L'étape séchage ne s'injecte que dans les cycles `locks`/`enfant` (le buildWashDay partagé).
- Le freeform n'éteint pas que l'hébdo : la phrase retwist de l'entre-deux lavages est remplacée
  aussi — une réponse doit corriger **tout** le texte qui la contredit.
- Enfant avec locks : questions posées volontairement (la maturation d'une lock d'enfant se joue
  chez le gardien) ; la chaleur/chimie reste exclue (garde D9 intacte).

## 5. Décisions assumées

- **Le freeform est traité comme une méthode complète**, pas comme une absence : on ne « retire pas
  le retwist », on écrit la séparation. Une routine qui tait la méthode du jour est une routine qui
  désarme la cliente.
- **Le séchage devient une étape du lavage** (et non un paragraphe de plus) : c'est la réponse qui
  change le plus le quotidien, elle doit être exécutable le jour même.
- Pas de question sur la cire / les beurres : le moteur interdit déjà le dépôt pour TOUT le segment
  (physique du segment, pas une habitude à respecter) — l'ajouter n'aurait eu aucun effet à tester.
- La « clarifying » (deep cleanse) n'est prescrite qu'en réponse à l'odeur persistante déclarée,
  jamais par défaut — les sources la disent sur-utilisée.

## 6. Reste ouvert (noté, hors périmètre)

- Poids/diamètre des locks (micro vs succulente) : porterait sur le séchage et la tension ; la
  largeur de cheveu la couvre partiellement — à ouvrir seulement si un retour client le demande.
- « Veut porter les locks » (avant passage à l'acte) : c'est un besoin de **préparation** (méthode de
  démarrage selon la texture) que le diagnostic actuel ne couvre pas — un mini-parcours dédiée, pas
  une question de plus, à arbitrer en chantier produit.
